# Case study connection: Adobe Analytics measurement

Adovo's [published case study](https://www.adovo.ai/case-studies/adobe-analytics-enterprise-implementation) combines examples from separate enterprise engagements. Members of today's Adovo team delivered measurement work in earlier roles; a later reporting pattern shows how shared definitions can support downstream reuse. The case is not one client's end-to-end implementation.

This repository demonstrates one narrow technique from that wider discipline: a testable page-view contract between a project-defined Adobe Client Data Layer event and a Web SDK XDM payload. It does not include report-suite configuration, consent management, channel attribution, or the enterprise reporting layer described in the case.

Use the [measurement playbook](aem-web-sdk-measurement-playbook.md) to plan and verify those surrounding decisions. The full case study on adovo.ai remains the source for delivery context and outcomes.
